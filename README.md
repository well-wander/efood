# efood

Projeto final do curso de Front-end da EBAC: uma plataforma de delivery de restaurantes, feita a partir do layout do Figma.

## Tecnologias

- React + TypeScript (Vite)
- Styled Components
- React Router

## Páginas

- `/` — Home, com a listagem de restaurantes
- `/perfil` — Perfil do restaurante, com o cardápio

## Como rodar

```bash
npm install
npm run dev
```
